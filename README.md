# SNHU-GO
 SNHU GO is a mobile application that combines real-time location-based services with a comprehensive list of events being held on the SNHU campus. 
 It provides information on events and shows their locations on an interactive map to help users find the events. 
 This was created last semester for my mobile applications course with Manish Tamang and Jamal Bah and presented at the SNHU CS showcase.
